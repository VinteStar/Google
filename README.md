# Anleitung: Google (Android) - Geräte

Bildschirm kabellos auf das Smartboard übertragen

Mit Google-Geräten kannst du Inhalte kabellos auf das Smartboard übertragen. 
Bei Android-Smartphones und -Tablets funktioniert dies je nach Gerät beispielsweise über „Bildschirm übertragen“, 
„Cast“ oder „Smart View“. 
Auf Chromebooks ist die Bildschirmübertragung abhängig von der verfügbaren Funktion und dem Smartboard-Modell.

# Schritt 1: Smartboard einschalten
Schalte das Smartboard ein und tippe auf Bildschirmfreigabe.

# Schritt 2: Verbindung vorbereiten
Stelle sicher, dass dein Google Gerät mit dem Gäste Wlan verbunden ist.

# Schritt 3: Bildschirmübertragung auf dem Gerät öffnen

Auf einem Android-Smartphone oder -Tablet:
1. Wische vom oberen Bildschirmrand nach unten, um die Schnelleinstellungen zu öffnen.
2. Suche nach einer Funktion wie „Bildschirm übertragen“, „Cast“ oder „Screen Cast“.
3. Falls die Funktion nicht sichtbar ist,
4. öffne die vollständigen Schnelleinstellungen oder überprüfe die Einstellungen deines Geräts.

Auf einem Chromebook:
1. Öffne die Einstellungen oder die Schnelleinstellungen.
2. Prüfe, ob eine Funktion zur drahtlosen Bildschirmübertragung verfügbar ist.
3. Falls keine entsprechende Funktion vorhanden ist,
4. verwende eine vom Smartboard unterstützte Übertragungsmethode.

# Schritt 4: Smartboard auswählen
Wähle in der Liste der verfügbaren Geräte das Smartboard aus. 
Der Gerätename wird normalerweise auf dem Smartboard angezeigt.

# Schritt 5: Verbindung bestätigen
Warte, bis die Verbindung hergestellt wurde. 
Falls auf dem Smartboard eine PIN oder eine Bestätigungsabfrage erscheint, 
folge den Anweisungen auf dem Bildschirm.

# Schritt 6: Inhalte übertragen
Nach erfolgreicher Verbindung werden – sofern die verwendete Funktion dies unterstützt –
die Inhalte deines Geräts auf dem Smartboard angezeigt. 
Du kannst nun beispielsweise Präsentationen, Bilder, Lern-Apps oder andere Inhalte zeigen.

# Schritt 7: Verbindung beenden
Öffne erneut die Bildschirmübertragung oder die Schnelleinstellungen deines Geräts und tippe auf „Trennen“,
„Übertragung beenden“ oder die entsprechende Option.
